# Modifier ou supprimer

Tout ce que vous avez saisi peut être changé.

!!! info "Qui peut modifier ?"
    Ces actions sont réservées au propriétaire du roadtrip et aux personnes qui ont le droit **Peut modifier**. Voir [Les droits de chacun](../partage/droits.md).

## Modifier un roadtrip

1. Sur le tableau de bord, cliquez sur <span class="ui">Modifier</span>.
   Vous pouvez aussi utiliser le lien **Modifier** dans *Mes roadtrips*.
2. Changez le nom, les dates ou la description.
3. Cliquez sur <span class="ui">Enregistrer</span>. Le message « Roadtrip modifié. » confirme le changement.

!!! warning "Raccourcir les dates"
    Si une étape se retrouve en dehors des nouvelles dates, l'application refuse. Par exemple : « L'étape 3 · Chamonix (19–22 oct.) sort de ces dates. Modifiez d'abord l'étape. »
    Déplacez ou supprimez d'abord l'étape, puis changez les dates du roadtrip.

## Modifier une étape

1. Ouvrez l'étape en cliquant dessus sur le tableau de bord.
2. Cliquez sur <span class="ui">Modifier</span>.
3. Faites vos changements : ville, dates, mode d'hébergement.
4. Cliquez sur <span class="ui">Enregistrer les modifications</span>.

Si quelqu'un d'autre a modifié cette étape en même temps que vous, l'application affiche : « Cette étape a été modifiée par une autre personne. » Cliquez sur <span class="ui">Recharger</span> pour voir la dernière version, puis refaites votre changement.

## Modifier ou supprimer un hébergement

Sur la page de l'étape :

- <span class="ui">Modifier l'hébergement</span> rouvre le formulaire ;
- <span class="ui">Supprimer l'hébergement</span> retire l'hébergement, mais **l'étape est conservée** ;
- <span class="ui">Marquer comme payé</span> passe l'hébergement de « À payer » à « Payé ».

## Supprimer une étape

1. Ouvrez l'étape.
2. Cliquez sur <span class="ui">Supprimer</span>.
3. Une fenêtre demande **« Supprimer l'étape N · Ville ? »**. Son hébergement sera supprimé aussi.
4. Confirmez avec <span class="ui">Supprimer l'étape</span>.

## Supprimer un roadtrip

Seul le **propriétaire** peut supprimer un roadtrip.

1. Dans **Mes roadtrips**, cliquez sur **Supprimer** sous le roadtrip.
2. La fenêtre **« Supprimer « *nom* » ? »** rappelle combien d'étapes seront effacées.
3. Confirmez avec <span class="ui">Supprimer le roadtrip</span>.

!!! danger "Action définitive"
    La suppression d'une étape ou d'un roadtrip **ne peut pas être annulée**. Elle s'applique aussi à **toutes les personnes** avec qui le roadtrip est partagé.
    Dans chaque fenêtre de confirmation, le bouton <span class="ui">Annuler</span> est sélectionné par défaut : appuyer sur Entrée ou Échap ne supprime rien.
