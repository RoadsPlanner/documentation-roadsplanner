# Guide d'utilisation

**Roadtrip** (aussi appelée *RoadsPlanner*) vous aide à préparer un voyage en plusieurs étapes : les villes où vous vous arrêtez, les dates, l'endroit où vous dormez chaque soir et le trajet sur une carte. Vous pouvez ensuite partager votre roadtrip avec les personnes qui voyagent avec vous.

Ce guide est fait pour les **débutants** : aucune connaissance technique n'est nécessaire. Suivez les pages dans l'ordre la première fois, puis revenez à celle dont vous avez besoin.

## Votre premier roadtrip en 5 minutes

1. **Créez un compte** avec votre prénom, votre e-mail et un mot de passe. → [Créer un compte](premiers-pas/creer-un-compte.md)
2. Cliquez sur <span class="ui">+ Nouveau roadtrip</span>, donnez-lui un nom et des dates. → [Créer un roadtrip](roadtrip/creer.md)
3. Ajoutez une **première étape** : une ville, une date d'arrivée et un nombre de jours. → [Ajouter une étape](roadtrip/ajouter-une-etape.md)
4. Dites **où vous dormez** : hôtel, camping, véhicule, famille… → [Choisir où dormir](roadtrip/hebergement.md)
5. Ouvrez **la carte** pour voir votre trajet. → [Voir le trajet](roadtrip/carte.md)

!!! tip "Bon à savoir"
    Roadtrip fonctionne dans un **navigateur web** (Chrome, Edge, Firefox, Safari), sur ordinateur comme sur téléphone. Vous pouvez aussi l'**installer** comme une application : voir [Installer l'application](premiers-pas/installer.md).

!!! warning "Une connexion Internet est nécessaire"
    Vos roadtrips sont enregistrés en ligne. Sans Internet, l'application affiche « Pas de connexion Internet » et vous ne pouvez rien consulter ni enregistrer.
