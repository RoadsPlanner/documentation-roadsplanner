# Questions fréquentes

??? question "L'application est-elle gratuite ?"
    Oui. Il suffit de [créer un compte](../premiers-pas/creer-un-compte.md).

??? question "Sur quels appareils puis-je l'utiliser ?"
    Sur tout appareil avec un navigateur récent (Chrome, Edge, Firefox, Safari) : ordinateur, tablette ou téléphone.
    Vous pouvez aussi l'[installer](../premiers-pas/installer.md).

??? question "Puis-je utiliser l'application sans Internet ?"
    Non. Vos roadtrips sont enregistrés en ligne. Sans connexion, l'application affiche « Pas de connexion Internet ».

??? question "J'ai oublié mon mot de passe, que faire ?"
    La réinitialisation n'est pas encore disponible. Si vous ne retrouvez pas votre mot de passe, vous pouvez créer un nouveau compte avec une autre adresse e-mail.

??? question "Pourquoi parle-t-on de « jours » et pas de « nuits » ?"
    Une étape compte les **jours** passés dans la ville, en incluant le jour d'arrivée. Le départ est calculé ainsi : arrivée + nombre de jours − 1.
    Par exemple, arriver le 16 et rester 3 jours veut dire repartir le 18.

??? question "Puis-je noter le prix de mon hébergement ?"
    Pas pour l'instant. L'application note seulement si l'hébergement est **payé** ou **à payer sur place**.

??? question "Mon étape n'apparaît pas sur la carte, ni dans la météo."
    La ville a sans doute été tapée à la main. Modifiez l'étape et choisissez la ville **dans la liste de suggestions**.
    Voir [Voir le trajet sur la carte](../roadtrip/carte.md#une-etape-napparait-pas).

??? question "Deux étapes peuvent-elles avoir les mêmes dates ?"
    Non. Les étapes se suivent sans se chevaucher. Le jour de départ d'une étape peut en revanche être le jour d'arrivée de la suivante.

??? question "Comment voyager à plusieurs sur le même roadtrip ?"
    Le propriétaire [partage le roadtrip](../partage/partager.md) avec l'e-mail de chaque personne. Chacune doit d'abord avoir un compte.

??? question "Que deviennent les pages Profil, Paramètres et Aide ?"
    Elles arrivent dans une prochaine version. Pour l'instant, elles affichent « Bientôt disponible ».

??? question "J'ai supprimé un roadtrip par erreur. Puis-je le récupérer ?"
    Non, la suppression est définitive, pour vous comme pour les personnes avec qui il était partagé.
