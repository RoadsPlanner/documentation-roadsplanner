# Problèmes et solutions

| Ce que vous voyez | Pourquoi | Que faire |
|---|---|---|
| **« Pas de connexion Internet »** | Votre appareil n'est pas connecté. | Vérifiez le Wi-Fi ou les données mobiles, puis cliquez sur <span class="ui">Réessayer</span>. |
| « Connexion impossible : rien n'a été enregistré. » | La connexion a été coupée pendant l'enregistrement. | Vérifiez votre connexion et cliquez de nouveau sur le bouton d'enregistrement. |
| « Votre session a expiré. Reconnectez-vous. » | Vous êtes resté longtemps sans utiliser l'application. | Reconnectez-vous : vous revenez sur la page où vous étiez. |
| « Trop de tentatives. Réessayez dans 15 minutes. » | 5 mots de passe faux en peu de temps. | Patientez 15 minutes. |
| **« Roadtrip introuvable »** | Le roadtrip a été supprimé, ou on vous a retiré l'accès. | Cliquez sur <span class="ui">Mes roadtrips</span> pour revenir à votre liste. |
| « Vous pouvez seulement consulter ce roadtrip. » | Vous avez le droit **Peut regarder**. | Demandez au propriétaire le droit **Peut modifier**. |
| « Seul le propriétaire peut partager ce roadtrip. » | Seul le créateur du roadtrip partage. | Demandez-lui d'ajouter la personne. |
| « Cette étape a été modifiée par une autre personne. » | Quelqu'un a changé l'étape en même temps que vous. | Cliquez sur <span class="ui">Recharger</span>, puis refaites votre modification. |
| « Météo indisponible pour le moment. » | Le service météo ne répond pas. | Réessayez plus tard. |
| « Carte indisponible pour le moment. » | Le fond de carte ne se charge pas. | Vérifiez la connexion. La liste des étapes reste affichée. |
| **« Page introuvable »** | Le lien est faux ou la page a été déplacée. | Cliquez sur <span class="ui">Mes roadtrips</span>. |

!!! tip "Le réflexe en cas de doute"
    Rechargez la page (touche **F5** sur ordinateur, ou tirez l'écran vers le bas sur téléphone). Si le problème continue, déconnectez-vous puis reconnectez-vous.
