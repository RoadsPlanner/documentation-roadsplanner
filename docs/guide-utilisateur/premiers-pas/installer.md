# Installer l'application

Roadtrip est une **application web installable** : vous pouvez l'ajouter à votre écran d'accueil ou à votre ordinateur et l'ouvrir comme une application, sans passer par le navigateur. L'installation est facultative et gratuite, et ne passe pas par un magasin d'applications.

L'application installée s'appelle **RoadsPlanner** et s'ouvre dans sa propre fenêtre.

=== "Ordinateur (Chrome ou Edge)"

    1. Ouvrez l'application dans Chrome ou Edge et connectez-vous.
    2. Dans la barre d'adresse, cliquez sur l'icône **Installer** (un petit écran avec une flèche).
    3. Confirmez avec **Installer**.

    L'application apparaît dans le menu Démarrer (Windows) ou dans le Launchpad (Mac).

=== "Android (Chrome)"

    1. Ouvrez l'application dans Chrome.
    2. Touchez le menu **⋮** en haut à droite.
    3. Choisissez **Ajouter à l'écran d'accueil** ou **Installer l'application**.

=== "iPhone et iPad (Safari)"

    1. Ouvrez l'application dans **Safari**.
    2. Touchez le bouton **Partager** (le carré avec une flèche vers le haut).
    3. Choisissez **Sur l'écran d'accueil**, puis **Ajouter**.

!!! info "Il n'y a pas de bouton « Installer » dans l'application"
    L'installation se fait uniquement par l'option de votre navigateur, comme décrit ci-dessus.

!!! warning "Toujours besoin d'Internet"
    Même installée, l'application a besoin d'une connexion. Sans réseau, elle affiche l'écran **« Pas de connexion Internet »** avec un bouton <span class="ui">Réessayer</span>. Vos roadtrips ne sont pas disponibles hors ligne.
