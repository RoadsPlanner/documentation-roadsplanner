# MKDocs
Page MKDocs qui rassemble la documentation du projet RoadsPlanner : contexte, personas, comparatif technologique et organisation des dépôts.

La page est accessible depuis https://roadsplanner.github.io/documentation-roadsplanner/

## développement

Si on veut y accéder en local pour du développement :

```bash
pip install -r requirements.txt
mkdocs serve
```

Le site est ensuite disponible sur http://127.0.0.1:8000/
